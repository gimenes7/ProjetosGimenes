# Pokedex

Aplicação web que consome a [PokeAPI](https://pokeapi.co/) para listar Pokémon e exibir seus detalhes.

## ✨ Funcionalidades

- Listagem dinâmica de Pokémon com dados obtidos da API
- Cards coloridos de acordo com o tipo de cada Pokémon
- Modal com detalhes ao clicar em um card (altura, peso, experiência base, tipo)
- Barra de pesquisa por nome ou número

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (Fetch API, DOM manipulation)
- [PokeAPI](https://pokeapi.co/)

## ▶️ Como rodar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador (recomendado usar a extensão Live Server do VS Code)
